# KMUTNB ECE Souvenir PCB

30 × 30 mm souvenir board. TOP: ECE KMUTNB logo silkscreen. BOTTOM: CMOS 555
astable blinking 14 orange 0402 LEDs laid out as 7-segment "ECE".
KiCad 10.0.6. Sources generated by scripts in `tools/`.

## Layout

| Path | What |
|---|---|
| `tools/parts.py` | BOM single source of truth (refs, values, footprints, LCSC codes) |
| `tools/gen_sch.py` | Generates `hardware/ece_souvenir.kicad_sch` |
| `tools/check_netlist.py` | Exports netlist via kicad-cli and diffs against spec |
| `tools/logo_trace.py` | Rasterises `art/ece_logo.png` into silkscreen runs (`art/ece_logo_runs.json`) |
| `tools/gen_pcb.py` | Generates `hardware/ece_souvenir.kicad_pcb`: outline, hole, placement, logo, rules (KiCad Python) |
| `tools/route.py` | Autoroutes: KiCad DSN export → Konnect `route_specctra_dsn` (local Freerouting 2.4.1) → KiCad SES import |
| `tools/konnect_mcp.py` | Minimal stdio client for the Konnect MCP server |
| `hardware/` | KiCad project |

## Circuit

555 astable; LEDs sink into OUT, so they light while OUT is LOW (discharge phase).

| Quantity | Formula | Value |
|---|---|---|
| t_on (LEDs lit) | 0.693·R2·C1 | 83 ms |
| t_off | 0.693·(R1+R2)·C1 | 776 ms |
| f | 1/(t_on+t_off) | 1.16 Hz, duty 9.7 % |
| I_LED each | (VCC − Vf − V_OL)/3.3 kΩ | ≈0.4 mA @3.3 V … 0.9 mA @5 V |

## Board

- 30 × 30 mm, R1 mm corners, 2-layer FR4 1.6 mm, white mask / black silk.
- TOP: logo only, 24 × 21.3 mm on F.SilkS at (3.0, 6.0); 2.5 mm NPTH keychain hole at (27, 3).
- BOTTOM: all parts. LEDs stand alone in the digit area at the spec positions (bottom-view x mirrored:
  `x_top = 30 − x_bv`). The fourteen 3.3 kΩ resistors form one row of vertical 0603s (1.6 mm pitch,
  y = 17.6) below the digits, grouped under the digit they feed. U1 at 270° below the row
  (OUT faces up); timing parts along the bottom edge; C2 centre 1.96 mm from pin 8.
- Rules (in `.kicad_pro`): track/clearance ≥ 0.20 mm, via 0.6/0.3 mm, copper–edge 0.3 mm,
  silk line ≥ 0.15 mm, text ≥ 1.0 mm. Net class `Power` (VCC, GND) 0.3 mm.

## Testing

Regenerate schematic, normalise to KiCad 10 format, run ERC and netlist check:

```bash
python3 tools/gen_sch.py && \
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli sch upgrade hardware/ece_souvenir.kicad_sch && \
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli sch erc --severity-all --exit-code-violations -o hardware/erc.rpt hardware/ece_souvenir.kicad_sch && \
python3 tools/check_netlist.py
```

Expected output (macOS 27, KiCad 10.0.6, Python 3.10):

```
wrote hardware/ece_souvenir.kicad_sch
Successfully saved schematic file using the latest format
Found 0 violations
Saved ERC Report to hardware/erc.rpt
6 named nets + 14 LED branch nets: OK
```

`hardware/erc.rpt` contains `** ERC messages: 0  Errors 0  Warnings 0`; all commands exit 0.

Regenerate the board and run DRC with schematic parity (KiCad's bundled Python provides `pcbnew`):

```bash
python3 tools/logo_trace.py && \
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 tools/gen_pcb.py && \
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli pcb drc --schematic-parity --severity-all -o hardware/drc.rpt hardware/ece_souvenir.kicad_pcb
```

Expected output, placement phase (unrouted; KiCad prints some wx debug lines on stderr, which you can ignore):

The 57 unconnected items are expected until the routing phase.

### Routing

Requires Konnect 0.13.0 (KiCad PCM plugin, `~/Documents/KiCad/10.0/3rdparty/plugins/com_github_mixelpixx_konnect`),
Freerouting 2.4.1 jar + Temurin JRE 25 in `~/.local/share/freerouting/`, KiCad GUI closed. Konnect's own
Specctra exporter only accepts front-side parts / rect pads / straight outlines, so KiCad's native DSN
exporter and SES importer do the file conversion and Konnect drives Freerouting. The DSN boundary is
inset 0.1 mm (Freerouting keeps 0.2 mm, rules want 0.3 mm to the edge) and top-layer (logo side)
traces cost 4–6× more, so the top is used only for crossings.

```bash
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 tools/route.py 30 && \
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli pcb drc --schematic-parity --severity-all -o hardware/drc.rpt hardware/ece_souvenir.kicad_pcb
```

Expected output (timestamps vary; wx debug lines on stderr omitted):

```
route_specctra_dsn: {'isError': False, 'result': {... 'final_state': 'COMPLETED', ... 'success': True}}
widened 6 neck-down segments to net-class width
imported hardware/routing/ece_souvenir-<stamp>.ses: 139 B.Cu segs (267.0 mm), 15 F.Cu segs (59.5 mm), 14 vias
Found 0 violations
Found 0 unconnected items
Found 0 schematic parity issues
Saved DRC Report to hardware/drc.rpt
```
