# KMUTNB ECE Souvenir PCB

30 × 30 mm souvenir board. TOP: ECE KMUTNB logo silkscreen. BOTTOM: CMOS 555
astable blinking 14 orange 0402 LEDs laid out as 7-segment "ECE".
KiCad 10.0.6. Sources generated by scripts in `tools/`.

## Circuit

555 astable (TLC555, CMOS). Q1 (MMBT3906 PNP) is a high-side switch fed from 555 OUT through
R6 = 4.7 kΩ: it conducts while OUT is LOW (discharge phase), so the LEDs flash briefly. Each digit
has one shared current-limit resistor (advisor review 2026-10-11); LED cathodes go to GND.

| Quantity | Formula | Value |
|---|---|---|
| t_on (LEDs lit) | 0.693·R2·C1 | 83 ms |
| t_off | 0.693·(R1+R2)·C1 | 776 ms |
| f | 1/(t_on+t_off) | 1.16 Hz, duty 9.7 % |
| I per digit | (VCC − Vce_sat − Vf)/R; E: 680 Ω, orange Vf ≈ 1.85 V; C: 220 Ω, white Vf ≈ 2.6 V | E ≈ 2.0 → 4.5 mA, C ≈ 2.9 → 10.5 mA (3.3 → 5 V) |
| I per LED (avg of digit) | I_digit / n | orange ≈ 0.4 → 0.9 mA (≈ 6 → 14 mcd), white ≈ 0.7 → 2.6 mA (≈ 5 → 17 mcd) |
| Q1 load / base | Σ digits; (VCC − V_EB − V_OL)/3.3 kΩ | ≤ 19.5 mA; I_B 0.8 … 1.3 mA (forced β ≈ 9–15) |

Design notes:
- Without Q1 the TLC555 could sink the ≈13 mA directly (100 mA typ / 150 mA abs-max, TI SLFS043K);
  Q1 was added on review so the 555 only supplies base current. A PNP (not NPN) is used so the LEDs
  stay on during the short OUT-LOW phase; an NPN low-side switch would light them ≈90 % of the time.
- Shared resistors trade matching for parts count: parallel LEDs on one resistor split current by
  exp(ΔVf / nV_T) (nV_T ≈ 50 mV at ~1 mA), so a 30 mV Vf spread can mean ≈1.8× current between
  segments of one digit. Use LEDs from one reel.
- White C: only ≈ 0.65 V of headroom at 3.3 V (Vf ≈ 2.6 V + Vce_sat), so the C dims fastest as the
  supply drops; below ≈ 3.0 V (e.g. a CR2032) it will barely light. Run from ≥ 3.3 V.

## Board

- 30 × 30 mm, R1 mm corners, 2-layer FR4 1.6 mm, white mask / black silk.
- TOP: logo only, 24 × 21.3 mm on F.SilkS at (3.0, 6.0); 2.5 mm NPTH keychain hole at (27, 3).
- BOTTOM: all parts **and all copper** (single-sided routing: no top traces, no vias, so the logo side
  is bare silkscreen on white mask). LEDs stand alone at the spec positions (bottom-view x mirrored:
  `x_top = 30 − x_bv`). LED polarity is 180° (a/g/d) and 270° (f/e) instead of the spec's 0°/90°:
  identical look, but every cathode then meets at each digit's inner-left corner, which is what makes
  one-layer routing possible. Digit resistors R3/R4/R5 sit under each digit; Q1 + R6 left of U1;
  U1 at 270°; C2 centre 1.96 mm from pin 8. Pads: + / − bottom right, OUT probe beside R6.
- One-layer topology (locked pre-routes in `tools/route.py`): TH (pin 2) and GND (pin 1) run under
  the SOIC body out of its left end; VCC is a ring round the board edge from pin 4 to pin 8, which
  keeps the LED field, Q1, OUT and pin 1 on the same side of every barrier.
- Board placed on the drawing sheet at (111.1825, 56.0585) mm; grid and drill/place origins are set
  to the board's top-left corner, so coordinates still read (0,0) at top-left.
- Hand-solder safety: router keepouts forbid foreign traces between the pads of every 2-pad part;
  `tools/route.py` also reports any trace between two pads of one part (currently none).
- EMI routing rules (checked by `tools/emi_check.py`):
  - no 90° or acute corners: pre-routes are drawn at 45°, autorouted corners are mitred to 45°
    (DRC-guarded); single layer, so there are no cross-layer crossings to keep perpendicular;
  - all copper ≥ 1.0 mm from the board edge (VCC ring centreline 1.15 mm, router boundary inset 0.5 mm);
  - B.Cu GND pour in all free space (0.3 mm clearance, thermal spokes for hand soldering, islands
    removed, so no floating copper) gives every trace an adjacent return path and guards the
    high-impedance TH/DIS nodes;
  - short explicit decoupling loop C2 ↔ U1 pin 1/8 (C2 centre 1.96 mm from pin 8);
  - timing cap C1 sits at the left end of U1 between the TH and GND under-body lanes (~1 mm loop);
  - LED_PWR (switched LED current) is one straight 0.3 mm bus; VCC/GND/LED_PWR in the 0.3 mm
    `Power` class; no stubs, no vias.
- Rules (in `.kicad_pro`): track/clearance ≥ 0.20 mm, via 0.6/0.3 mm, copper–edge 0.3 mm,
  silk line ≥ 0.15 mm, text ≥ 1.0 mm. Net class `Power` (VCC, GND, LED_PWR) 0.3 mm.

### Routing (single-sided)

Requires Konnect 0.13.0 (KiCad PCM plugin, `~/Documents/KiCad/10.0/3rdparty/plugins/com_github_mixelpixx_konnect`),
Freerouting 2.4.1 jar + Temurin JRE 25 in `~/.local/share/freerouting/`, KiCad GUI closed. Konnect's own
Specctra exporter only accepts front-side parts / rect pads / straight outlines, so KiCad's native DSN
exporter and SES importer do the file conversion and Konnect's `route_specctra_dsn` drives Freerouting.
DSN tweaks: boundary inset 0.1 mm (0.3 mm edge rule), F.Cu inactive and vias off (one layer), and
between-pad keepouts. Note: Freerouting 2.4.1 silently ignores the whole netlist if a `keepout`
precedes `autoroute_settings` in `(structure ...)`.

```bash
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 tools/route.py 60 && \
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli pcb drc --schematic-parity --severity-all -o hardware/drc.rpt hardware/ece_souvenir.kicad_pcb
```

Expected output for the committed board (Freerouting is heuristic: segment counts/length can differ
between runs; what must hold is 0 F.Cu, 0 vias, 0 crossings, DRC all zero):

